# 量化套利独立文章页设计

## 目标

同步 `/Users/karp/Code/Axon/PM作品集/量化理财/` 中已经更新的套利内容，并让每篇套利 HTML 单独打开时符合 Leon Blog 的文章详情页展示条件。

## 已确认的页面边界

- 专题首页 `/arbitrage/` 保留左侧策略导航和右侧 iframe 阅读区。
- 独立文章页保留 Leon Blog 顶部导航、主题背景和单栏主文章内容区。
- 独立文章页不显示作者卡、公告、目录、最新文章等右侧栏。
- 不增加独立大标题封面，不改变文章的图解、公式、表格和计算器交互结构。
- 直接访问文章 URL 与在专题 iframe 中查看时均可阅读；iframe 中隐藏重复的博客顶部导航，仅显示正文。
- 支持移动端和系统明暗模式。

## 内容同步范围

- 同步源目录已修改的 `01`、`02`、`03`、`08`。
- 新增 `10-期权套利.html`。
- 更新专题首页为十种套利，同时保留博客入口和移动端可达性。
- 未变化页面不覆盖业务内容，只接入统一展示外壳。

## 实现方式

- `assets/common.css` 统一提供 Leon Blog 色彩、背景、导航、单栏文章卡片及 iframe 嵌入态样式。
- `assets/theme-shell.js` 在每篇静态文章载入时生成博客导航，并根据是否处于 iframe 自动切换独立页/嵌入态。
- 每篇 HTML 仅引用共享 CSS 与共享脚本，避免复制整套导航结构。
- 使用自动化测试检查十篇文章、共享外壳、右侧栏排除、内容同步和移动端规则。

## 验收

- 独立打开任一 `01`–`10` 页面，可见博客导航、主题背景和单栏正文。
- 页面中不存在 `aside-content`、作者卡、公告卡、目录卡和最新文章卡。
- 在 `/arbitrage/` iframe 中查看时不重复显示顶部导航。
- `npm test` 与 `npm run build:leon-root` 通过。
- 桌面与移动视口均完成实际页面检查。
