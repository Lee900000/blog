# 关于页活跃记录

本地预览 `/about/`。只增加可视化，不接入跟踪服务。

## 数据来源

- 博客：公开文章显式 `date` / `updated` 字段，以及本工作区 Git 历史。不会使用文件修改时间。
- 发布和更新独立计数；相同文章同一天的显式 `updated` 与 Git 更新去重；一天不同提交可多次计数。
- 每次提交中样式、页面文案、主题配置等变动计一次维护。单次超过 50 篇文章的批量变动按维护计数，避免导入/路由迁移制造虚假写作峰值。此为明确的估算规则，不是语义识别。
- 未提交变动、没有记录的历史操作不统计；删除文章不保留明细。237、704 和未发布文章不进入统计。
- 页面保留年度热力图与发布、更新、维护计数，支持年份切换和日期详情。

## 刷新

Hexo 构建生成 `assets/activity.json`；博客统计每次构建更新。全部数据来自本地文章和 Git 历史，无需 GitHub 登录或网络请求。

前端无外部接口请求、没有令牌；失败显示提示，年份切换和日期详情均在浏览器本地计算。
