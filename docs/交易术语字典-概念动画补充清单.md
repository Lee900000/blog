## 设计原则与验收要求

- 每个主题讲一个清楚的问题：先发生什么、画面如何变化、最后得到什么结果。下文每个主题均有三段分镜、具体例子与适用边界。
- 真正发生运动：数量块转移、订单被逐档消耗、价格线移动、资金柱增减、状态节点切换。不能只有文案轮播、闪点或静态框图。
- 按概念选择画面：订单簿、价格曲线、资金账本、双向时间线、生命周期、单位换算、持仓盒。不得统一套“四个圆圈加进度条”。
- 大白话标题与字幕；公式全部使用中文变量，独立金色公式区域突出。API 原字段只用于字段对应标签，不代替中文公式。
- 同义词与字段共享已确认的主题，词条入口只展示与自身相关的分支和焦点。共享不等于把全部分支一次性堆在画面上。
- 已有动画保留并单独登记；需要补分支时在原主题基础上补，不混入旧的自制静态图解，也不在有动画的词条下另添“交互示意”。
- 沿用词条中的“查看概念动画”位置；提供播放/暂停、重播和步骤切换。切换词条重置到起点，离开视口暂停；无需外部网站才能播放。
- 建议每段动画约 8–16 秒，结束停留在结论；循环不应制造“脱锚必回归”“止损必成交”等错误因果。减少动态偏好下提供可逐步阅读的静态关键帧。
- 金额、价格、比例均为教学假设，持续显示“示例数据”。不接入真实行情或外部跟踪。
- 每个正式动画在制作前关联到具体来源页、平台、产品、账户模式和核对日期。总文档首页只能作为检索入口，不能假装已核实该公式。
- 交易所阈值、接口参数范围、枚举支持、结算口径等仍需按 Binance / OKX 对应官方文档逐项核对；本清单不是对全部现行规则的确认。资料含糊的项目已在对应边界中标出，核实前不制作确定性机制。
- 验收逐个入口点击：动画能加载、实际播放、重播、暂停、切换不串内容；手机不裁切；公式单位和算例对得上。完成数按词条入口覆盖计算，同时单列复用主题数。

## 建议先审的第一批主题

先审最影响小白理解、且目前缺动画的主题；不是只做以下部分，后文覆盖全部缺失项。

- [市价单逐档成交](#story-012)：买单写入目标数量 → 从最优卖价开始逐档消耗 → 列出实际成交均价与未成交可能。
- [分笔成交与加权均价](#story-013)：目标订单拆成若干数量块 → 部分数量按不同价格成交 → 更新已成交、剩余与成交均价。
- [撤单与成交竞速](#story-014)：未成交订单等待 → 撤单请求与对手成交请求沿两条时间线前进 → 两种先后顺序分别得到已撤或已成交。
- [四种订单有效方式](#story-017)：同一份盘口复制为四组 → 同一笔订单分别采用四种策略 → 对照等待、部分成交后撤、全成否则撤、只挂单结果。
- [触发条件不是成交价格](#story-022)：显示最新价、标记价、指数价三条独立线 → 所选参考价穿过触发线 → 触发后生成市价或限价订单，再等待成交。
- [合约张数换算](#story-045)：放大一张合约的规格卡 → 多张合约叠加成对应标的数量或美元面值 → 切换面值单位并显示换算结果。
- [单向净仓与双向分仓](#story-044)：同样先买 3 再卖 2 → 单向模式显示净多 1 → 双向模式明确开空参数后显示多 3、空 2。
- [初始保证金与杠杆占用](#story-060)：先固定名义价值 → 选择杠杆并从可用资金分配保证金 → 改变杠杆只改变示例初始要求而非同仓位盈亏。
- [名义价值与实际本金](#story-084)：先显示数量与当前参考价格 → 乘积组成名义价值柱 → 旁边独立保留保证金，避免两者混淆。
- [浮动盈亏与落袋盈亏](#story-056)：仓位持有期间价格上下变化 → 部分平仓将对应部分从浮动栏转入已实现栏 → 手续费和资金费在独立栏扣增。
- [钱包余额、账户权益与可用余额](#story-085)：入金形成余额 → 浮动盈亏改变权益但不等于钱包已结算余额 → 扣除示例占用后标明可用资金。
- [成交手续费怎么算](#story-078)：先完成一笔成交并确定成交身份 → 匹配示例费率与折扣条件 → 从明确币种扣费并累加到费用账本。
- [资金费用的金额与收付](#story-079)：结算时点读取适用仓位和费率 → 正费率与负费率分别高亮付费方向 → 费用进入账单且累计值更新。
- [风险分层、档位与杠杆上限](#story-063)：名义价值沿横轴变大 → 进入下一档后切换最大杠杆与风险参数 → 边界前后同时显示档位区间与适用要求。
- [杠杆借贷强平价格](#story-076)：本金和借款汇总成买入资产 → 资产价格下降但借款及利息仍在 → 资产对负债的比值触及假设处置线。
