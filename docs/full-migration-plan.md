# 全量迁移与原生主题计划

## 本轮目标

用户已验收十篇样本，授权迁移其余公开文章并恢复 Butterfly 原生背景、布局与样式。当前归档去重发现 867 篇，编号以 `migration/discovery.json` 为准，每篇独立验收项见 `docs/article-checklist.md`。

仅限本地预览和私有 GitHub 源码保存；不访问 SSH/数据库，不替换原 Typecho，不修改 Nginx/DNS/证书，不部署线上，不迁移评论或访问受限内容。

## 并行分工

- 迁移工作：抓取、检查点、转换、媒体记录、867 篇逐项验收；维护 migration、tests、package、posts、migrated assets。
- 主题工作：仅恢复主题配置、原生首屏/文章卡片/侧栏，定位官方展示图使用的青绿色烟雾人物照片；不把设备宣传海报当网页背景。
- 主会话：整合检查、真实页面预览、隐私扫描、分批提交与远端读回。

## 执行顺序

1. [x] 固定本轮公开文章清单，创建工作分支。
2. [ ] 扩展脚本并运行全量迁移，限速、超时、重试与逐篇检查点。
3. [ ] 恢复原生主题布局，官方背景资源来源可追溯。
4. [ ] 构建并按发现集合逐篇核对，记录原站已坏资源和新增失败，更新文章清单。
5. [ ] 浏览器验证首页背景、分页、归档和代表文章；模拟手机宽度不称真实手机验收。
6. [ ] 仅将审核后的源码/公开资源推送私有分支，读回提交哈希；交付本地预览。

## 验收门槛

- 867 个发现 ID 都有明确结果；不可把抓取数、转换数、构建数混成一个完成数。新增/消失文章单独解释。
- 保留旧文章路径；日期与源站实际时间一致，分类不误变层级；代码、表格和 Mermaid 保真。
- 原站资源缺失如实列入报告，不伪造附件，也不因图片失败丢掉正文。
- 样本内外链接按完整迁移集合改写；无法迁移对象保留明确原站地址。
- 首页恢复主题原生大图与卡片；图片存在时使用文章自身资源，不编造封面。
- 不把认证配置、原始整页缓存、日志、数据库或私密文章提交仓库。
- 不以“还可验证”为理由扩大到生产部署；用户确认效果后停止。

## 已知边界

旧文章 877 的相对文档链接原站已为404。全量可能发现更多旧资源失效；须逐项分类交付，不承诺修复并不存在的原始文件。主题原生第三方库可继续使用 CDN，纯静态不等于完全离线。
