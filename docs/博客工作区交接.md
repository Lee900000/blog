## 安全发布

先提交已经审阅的源码变更，并确认工作区干净：

```sh
git status --short
npm run publish:leon -- --confirm leon-book.github.io
```

`tools/publish-leon-root.mjs` 会执行以下硬性检查：

1. GitHub CLI 当前账号必须是 `leon-book`。
2. 唯一目标必须是 `https://github.com/leon-book/leon-book.github.io.git`。
3. 必须输入完整确认词 `leon-book.github.io`。
4. 源码工作区必须干净。
5. 全量测试和根域构建必须成功。
6. 构建产物不得包含文章 `237`、`704`。
7. 只在系统临时目录克隆 Pages 仓库；校验远端后才提交和推送。

不要直接运行 `git push` 发布页面，也不要把源码分支强推到 Pages 仓库。
