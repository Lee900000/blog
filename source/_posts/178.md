在Linux下使用shell的时候，为方便起见，偶尔会用到一下数组。数组的申明方式是：

```c
array=(element1 element2 element3 .... elementN)  
```

也就是直接用圆括号包数组元素包起来，数组元素之间用空格隔开就行了。

数据的读取如下

```c
#echo ${array[0]}  
#echo ${array[index]}  
```

数组的遍历用到一个取全部：

```c
${array[@]}  
```

完整示例如下：

```c
for data in ${array[@]}  
do  
    echo ${data}  
done  
```
