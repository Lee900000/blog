## 成功安裝後我們回到 `Terminal`

安裝成功後，我們可以透過 `Terminal` 使用 which 確認是否安裝成功，可以試著在 Terminal 輸入以下命令：

```shell
$ which npm
/usr/local/bin/npm

$ which node
/usr/local/bin/node
```

# 启动一個 web server

我们可以另外写一個 web server 的 app 来测试一下，这边我们使用 http 来启动一个 web server，实操代码如下:

```js
// server.js

const http = require('http');

const server = http.createServer((req, res) => {
  res.statusCode = 200;
  res.setHeader('Content-Type', 'text/plain');
  res.end('Hello World\n');
});

server.listen(3000, 'localhost', () => {
  console.log('Server running at http://localhost:3000/');
});
```

接着我们透过 node 来启动这个web server, 输入一下命令:

```js
$ node server.js
Server running at http://localhost:3000/
```

![2024-08-12T12:25:11.png](/assets/migrated/f73dd34ac261f241e5c7.png "2024-08-12T12:25:11.png")

接着我们前往浏览器点开 [http://localhost:3000/](http://localhost:3000/)，就可以看到 Hello World 的字串啦！結果如下图，如果有看到 Hello World 就代表我们完全成功啦！
