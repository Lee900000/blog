MongoDB 是一个高性能、无模式的 NoSQL 数据库，广泛用于现代应用程序。本文将介绍如何通过二进制包在 Linux 系统上安装 MongoDB。

## 1\. 下载 MongoDB 二进制包

### 1.1 访问 MongoDB 官方网站

前往 [MongoDB 下载中心](https://www.mongodb.com/try/download/community) 选择适合您操作系统的版本。

### 1.2 使用 wget 下载

您也可以使用 `wget` 命令直接下载 MongoDB 二进制包。以下以 MongoDB 6.0 为例：

```bash
wget https://fastdl.mongodb.org/linux/mongodb-linux-x86_64-ubuntu2004-6.0.0.tgz
```

请根据您的操作系统和 MongoDB 的版本更新下载链接。

## 2\. 解压缩包

下载完成后，使用以下命令解压缩：

```bash
tar -zxvf mongodb-linux-x86_64-ubuntu2004-6.0.0.tgz
```

## 3\. 移动文件到合适的位置

将解压后的文件移动到 `/usr/local` 或其他可执行路径：

```bash
sudo mv mongodb-linux-x86_64-ubuntu2004-6.0.0 /usr/local/mongodb
```

## 4\. 配置环境变量

为了方便使用 MongoDB 的命令，您可以将 MongoDB 的 `bin` 目录添加到系统的 `PATH` 环境变量中。

### 4.1 编辑 `.bashrc` 文件

```bash
nano ~/.bashrc
```

在文件末尾添加以下内容：

```bash
export PATH=$PATH:/usr/local/mongodb/bin
```

### 4.2 使更改生效

```bash
source ~/.bashrc
```

## 5\. 创建数据目录

MongoDB 默认使用 `/data/db` 作为数据存储目录。您可以使用以下命令创建该目录并设置权限：

```bash
sudo mkdir -p /data/db
sudo chown `id -u` /data/db
```

## 6\. 启动 MongoDB

使用以下命令启动 MongoDB：

```bash
mongod --dbpath /data/db
```

如果您希望在后台运行 MongoDB，可以使用以下命令：

```bash
mongod --dbpath /data/db --fork --logpath /var/log/mongodb.log
```

## 7\. 连接到 MongoDB

在另一个终端窗口中，您可以使用 `mongo` 命令连接到 MongoDB：

```bash
mongo
```

## 8\. 验证安装

连接成功后，您可以运行以下命令验证 MongoDB 是否正常工作：

```javascript
db.runCommand({ ping: 1 })
```

如果返回 `{ "ok": 1 }`，则表示 MongoDB 已成功安装并正常运行。
