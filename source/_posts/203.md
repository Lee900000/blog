Redis 是一个高性能的键值数据库，广泛用于缓存、消息队列和实时分析等场景。`redis-cli` 是 Redis 的命令行工具，允许用户与 Redis 服务器进行交互。在这篇文章中，我们将总结一些常用的 `redis-cli` 命令，帮助您更有效地使用 Redis。

## 1\. 连接 Redis 服务器

要连接到 Redis 服务器，可以使用以下命令：

```bash
redis-cli -h <hostname> -p <port>
```

-   `<hostname>`：Redis 服务器的主机名（默认为 `127.0.0.1`）。
-   `<port>`：Redis 服务器的端口号（默认为 `6379`）。

示例：

```bash
redis-cli -h 127.0.0.1 -p 6379
```

如果 Redis 服务器设置了密码，可以使用 `-a` 选项：

```bash
redis-cli -h 127.0.0.1 -p 6379 -a <password>
```

## 2\. 常用命令

### 2.1 键操作

-   **查看所有键**：
    
    ```bash
    keys *
    ```
    
-   **检查键是否存在**：
    
    ```bash
    exists <key>
    ```
    
-   **删除键**：
    
    ```bash
    del <key>
    ```
    

### 2.2 字符串操作

-   **设置字符串值**：
    
    ```bash
    set <key> <value>
    ```
    
-   **获取字符串值**：
    
    ```bash
    get <key>
    ```
    
-   **增加字符串值**：
    
    ```bash
    incr <key>
    ```
    

### 2.3 哈希操作

-   **设置哈希字段**：
    
    ```bash
    hset <hash> <field> <value>
    ```
    
-   **获取哈希字段**：
    
    ```bash
    hget <hash> <field>
    ```
    
-   **获取所有哈希字段**：
    
    ```bash
    hgetall <hash>
    ```
    

### 2.4 列表操作

-   **添加元素到列表**：
    
    ```bash
    lpush <list> <value>
    ```
    
-   **获取列表元素**：
    
    ```bash
    lrange <list> <start> <end>
    ```
    

### 2.5 集合操作

-   **添加元素到集合**：
    
    ```bash
    sadd <set> <value>
    ```
    
-   **获取集合所有元素**：
    
    ```bash
    smembers <set>
    ```
    

### 2.6 有序集合操作

-   **添加元素到有序集合**：
    
    ```bash
    zadd <zset> <score> <value>
    ```
    
-   **获取有序集合的排名**：
    
    ```bash
    zrank <zset> <value>
    ```
    

## 3\. 事务和管道

-   **开始事务**：
    
    ```bash
    multi
    ```
    
-   **执行事务**：
    
    ```bash
    exec
    ```
    
-   **放弃事务**：
    
    ```bash
    discard
    ```
    

## 4\. 服务器信息

-   **获取服务器信息**：
    
    ```bash
    info
    ```
    
-   **检查 Redis 服务器状态**：
    
    ```bash
    ping
    ```
    

## 5\. 关闭连接

要退出 `redis-cli`，可以使用以下命令：

```bash
exit
```

## 结论

通过以上总结，您现在应该对 `redis-cli` 的常用命令有了一个基本的了解。这些命令将帮助您更有效地与 Redis 数据库进行交互。
