# 虚拟机克隆无局域网ip地址 解决办法

目的是屏蔽

修改

```c
 vim /etc/sysconfig/network-scripts/ifconfig-eth0

DEVICE="eth0"
BOOTPROTO=dhcp
NM_CONTROLLED="yes"
ONBOOT=yes
TYPE="Ethernet"
#UUID="a900ea6a-7f3d-4293-b873-76315cfcac12" 屏蔽
DEFROUTE=yes
IPV4_FAILURE_FATAL=yes
IPV6INIT=no
NAME="System eth0"
#HWADDR=00:0C:29:CA:49:7C  屏蔽
PEERDNS=yes
PEERROUTES=yes
```

屏蔽目的是动态生成ip地址  
删除`70-persistent-net.rules`规则文件

```c
 mv /etc/udev/rules.d/70-persistent-net.rules /tmp
```

`init 6` 重启
