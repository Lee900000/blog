# 安装Golang build 包

点击 `Preferences` > `Package control` 菜单(`MAC`快捷键 `shift` + `command` + `p`)

在弹出的输入框输入

```c
install
```

选择 `Package control:install package`

然后输入

```c
Golang build 
```

选择`Golang build`安装

# 设置配置参数

安装好之后点击

`Preferences Preferences` > `Package Setting` > `Golang Config` > `Setting - User`

设置一些参数

```c
{
    "PATH": "/usr/local/bin",
    // 这里改成你自己的GOPATH
    "GOPATH": "/Users/chenxiangan/go"
}
```

`GOPATH`可以通过运行`go env`获取

运行  
`ctrl+b` 第一次会弹出的`go file run`等一堆选项，直接点击`run`的那个，以后直接`ctrl+b`运行就行了。
