Docker 是一个开源的应用容器引擎，允许开发者将应用及其依赖打包到一个可移植的容器中。以下是一些常用的 Docker 操作命令和基本使用技巧。

## 1\. 安装 Docker

在不同平台上安装 Docker 的步骤略有不同，以下是常见平台的安装步骤。

### 1.1 Ubuntu

```bash
sudo apt update
sudo apt install docker.io
sudo systemctl start docker
sudo systemctl enable docker
```

### 1.2 CentOS

```bash
sudo yum install docker
sudo systemctl start docker
sudo systemctl enable docker
```

### 1.3 Windows 和 macOS

访问 [Docker 官网](https://www.docker.com/get-started) 下载并安装 Docker Desktop。

## 2\. 基本命令

### 2.1 查看 Docker 版本

```bash
docker --version
```

### 2.2 查看运行中的容器

```bash
docker ps
```

### 2.3 查看所有容器（包括停止的）

```bash
docker ps -a
```

### 2.4 创建并运行容器

```bash
docker run -d --name my_container nginx
```

### 2.5 停止容器

```bash
docker stop my_container
```

### 2.6 启动容器

```bash
docker start my_container
```

### 2.7 删除容器

```bash
docker rm my_container
```

### 2.8 查看镜像

```bash
docker images
```

### 2.9 拉取镜像

```bash
docker pull nginx
```

### 2.10 删除镜像

```bash
docker rmi nginx
```

## 3\. 容器操作

### 3.1 进入容器

```bash
docker exec -it my_container /bin/bash
```

### 3.2 查看容器日志

```bash
docker logs my_container
```

### 3.3 复制文件到容器

```bash
docker cp /path/to/local/file my_container:/path/in/container
```

### 3.4 复制文件从容器到本地

```bash
docker cp my_container:/path/in/container /path/to/local/directory
```

## 4\. 网络操作

### 4.1 查看网络

```bash
docker network ls
```

### 4.2 创建网络

```bash
docker network create my_network
```

### 4.3 连接容器到网络

```bash
docker network connect my_network my_container
```

### 4.4 断开容器与网络的连接

```bash
docker network disconnect my_network my_container
```

## 5\. Docker Compose

### 5.1 安装 Docker Compose

使用以下命令安装 Docker Compose：

```bash
sudo curl -L "https://github.com/docker/compose/releases/download/$(curl -s https://api.github.com/repos/docker/compose/releases/latest | grep -oP '"tag_name": "\K(.*)(?=")')/docker-compose-$(uname -s)-$(uname -m)" -o /usr/local/bin/docker-compose
sudo chmod +x /usr/local/bin/docker-compose
```

### 5.2 创建 `docker-compose.yml` 文件

```yaml
version: '3'
services:
  web:
    image: nginx
    ports:
      - "8080:80"
```

### 5.3 启动服务

```bash
docker-compose up -d
```

### 5.4 停止服务

```bash
docker-compose down
```

## 6\. 其他常用命令

### 6.1 清理未使用的镜像和容器

```bash
docker system prune
```

### 6.2 查看 Docker 资源使用情况

```bash
docker stats
```
