首先需要先安装 abd.

[`Android` 调试桥 (adb)](https://developer.android.com/tools/adb?hl=zh-cn) 是一种功能多样的命令行工具，可让您与设备进行通信.

## Mac安装adb，最简单的办法是用homebrew

```bash
brew install --cask android-platform-tools
```

安装后 在选择一个图形界面工具

-   [scrcpy](https://github.com/Genymobile/scrcpy)
-   [QtScrcpy](https://github.com/barry-ran/QtScrcpy/blob/dev/README_zh.md)

我选择安装的是 `QtScrcpy` :
