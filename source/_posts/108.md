在 Web 开发中，处理 Excel 文件是一个常见的需求。PHPExcel 是一个流行的 PHP 库，可以帮助我们读取、写入和操作 Excel 文件。本文将介绍如何使用 PHPExcel 来读取 Excel 文件中的数据。

## PHPExcel 简介

PHPExcel 是一个强大的 PHP 库，可以处理 Excel 文件的读写操作。它提供了丰富的功能和 API，使得在 PHP 环境中处理 Excel 文件变得简单而高效。

## 读取 Excel 文件

### 步骤一：安装 PHPExcel

首先，您需要下载 PHPExcel 并将其引入到您的 PHP 项目中。您可以从 PHPExcel 的官方 GitHub 仓库进行下载。

### 步骤二：加载 Excel 文件

在您的 PHP 代码中，您需要加载您要读取的 Excel 文件。假设您的 Excel 文件名为 `example.xlsx`，可以使用以下代码加载该文件：

```php
require 'path/to/PHPExcel/Classes/PHPExcel.php';

$inputFileName = 'path/to/your/excel/example.xlsx';
$objPHPExcel = PHPExcel_IOFactory::load($inputFileName);
```

### 步骤三：读取数据

一旦加载了 Excel 文件，您可以通过 PHPExcel 提供的 API 来读取文件中的数据。以下是一个简单的示例，读取第一个工作表中的数据：

```php
$sheet = $objPHPExcel->getSheet(0); // 获取第一个工作表
$highestRow = $sheet->getHighestRow(); // 获取最大行数
$highestColumn = $sheet->getHighestColumn(); // 获取最大列数

for ($row = 1; $row <= $highestRow; $row++) {
    $rowData = $sheet->rangeToArray('A' . $row . ':' . $highestColumn . $row, NULL, TRUE, FALSE);
    print_r($rowData);
}
```

### 步骤四：处理数据

根据您的需求，您可以进一步处理从 Excel 文件中读取的数据，例如将其存入数据库、进行数据分析等操作。
