通过mysql 管理账号 设置表单个字段权限, 限制表记录被修改的问题.

针对`test`账号 `db1`库下面的t1表的 `id`，`name`, `age` 字段授予`select`, `insert`权限;

授权格式 `select`(要授权的字段，要授权的字段) 用户括号 括起来、`insert()`

```c
mysql> grant select(id,name,age),insert(id,name,age) on db1.t1 to 'test'@'localhost';
Query OK, 0 rows affected (0.11 sec)
```

授权记录查询

```c
select * from mysql.columns_priv;
```

该表也是不要拥有`delete` 权限 , 小心被绕开. 对比上篇文章 [Mysql 触发器 禁止修改数据表的某一字段](https://www.3pub.cn/index.php/archives/723.html) 的方案要简单一些. 诶没有DBA 啥都要自己想
