在 Linux 系统中，您可以使用多种工具来查看实时的带宽流量情况。以下是一些常用的方法和工具：

## 1\. `iftop`

`iftop` 是一个实时流量监控工具，可以显示网络接口的带宽使用情况。

### 安装

在 Debian/Ubuntu 系统上：

```bash
sudo apt install iftop
```

在 CentOS/RHEL 系统上：

```bash
sudo yum install iftop
```

### 使用

运行 `iftop`，指定要监控的网络接口（例如 `eth0`）：

```bash
sudo iftop -i eth0
```

### 功能

-   显示实时流量。
-   可以按源或目标 IP 排序。
-   支持过滤特定 IP 或端口。

## 2\. `nload`

`nload` 是一个简单的实时网络流量监控工具，可以显示流入和流出的带宽使用情况。

### 安装

在 Debian/Ubuntu 系统上：

```bash
sudo apt install nload
```

在 CentOS/RHEL 系统上：

```bash
sudo yum install nload
```

### 使用

运行 `nload`，指定要监控的网络接口：

```bash
nload eth0
```

### 功能

-   显示实时流量图表。
-   显示流入和流出的带宽使用情况。
-   支持多个网络接口的监控。

## 3\. `vnstat`

`vnstat` 是一个网络流量监控工具，可以记录网络流量并生成统计信息。

### 安装

在 Debian/Ubuntu 系统上：

```bash
sudo apt install vnstat
```

在 CentOS/RHEL 系统上：

```bash
sudo yum install vnstat
```

### 使用

首先，启动 `vnstat` 服务：

```bash
sudo systemctl start vnstat
sudo systemctl enable vnstat
```

然后，查看实时流量：

```bash
vnstat -l -i eth0
```

### 功能

-   提供历史流量统计。
-   显示实时流量。
-   支持多个网络接口。

## 4\. `bmon`

`bmon` 是一个 Bandwidth Monitor 工具，提供实时的带宽监控和统计。

### 安装

在 Debian/Ubuntu 系统上：

```bash
sudo apt install bmon
```

在 CentOS/RHEL 系统上：

```bash
sudo yum install bmon
```

### 使用

运行 `bmon`：

```bash
bmon
```

### 功能

-   显示实时流量和统计信息。
-   支持图形化显示。
-   可以监控多个接口。

## 5\. `iptraf`

`iptraf` 是一个交互式的网络流量监控工具，提供详细的流量统计。

### 安装

在 Debian/Ubuntu 系统上：

```bash
sudo apt install iptraf
```

在 CentOS/RHEL 系统上：

```bash
sudo yum install iptraf
```

### 使用

运行 `iptraf`：

```bash
sudo iptraf
```

### 功能

-   显示实时流量情况。
-   提供详细的连接信息。
-   支持界面切换。
