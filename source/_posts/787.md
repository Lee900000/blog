查看composer当前版本

```
composer -v
```

要回滚到composer版本1，只需执行以下命令

```
composer self-update --1
```

当您想回到版本2时（在更新或删除不兼容的插件之后，您应该这样做）

```
composer self-update --2
```

切换到指定版本

```
composer self-update 2.0.14
```
