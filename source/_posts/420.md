如果您在 Mac 上设置了环境变量，并发现每次打开终端都需要手动执行 `source ~/.bash_profile` 才能生效，这可能是因为您的终端没有自动加载配置文件。以下是解决这一问题的几种方法。

## 1\. 确认使用的 Shell

首先，检查您正在使用的 Shell。macOS 默认使用 `zsh`，但如果您手动切换到 `bash`，则需要确保配置文件正确。

### 检查当前 Shell

在终端中运行以下命令：

```bash
echo $SHELL
```

如果输出为 `/bin/zsh`，您正在使用 `zsh`，那么需要修改 `~/.zshrc` 文件。如果是 `/bin/bash`，则修改 `~/.bash_profile` 文件。

## 2\. 对于 Zsh 用户

如果您使用的是 `zsh`，请将环境变量配置添加到 `~/.zshrc` 文件中，而不是 `~/.bash_profile`。

### 编辑 `~/.zshrc`

```bash
nano ~/.zshrc
```

在文件末尾添加您的环境变量配置，例如：

```bash
export PATH=$PATH:/usr/local/go/bin
export GOPATH=$HOME/go
```

保存文件后，执行以下命令使更改生效：

```bash
source ~/.zshrc
```

## 3\. 对于 Bash 用户

如果您使用的是 `bash`，并且仍然需要手动执行 `source ~/.bash_profile`，请确保您在 `~/.bash_profile` 中的配置是正确的。

### 编辑 `~/.bash_profile`

```bash
nano ~/.bash_profile
```

添加您的环境变量配置，例如：

```bash
export PATH=$PATH:/usr/local/go/bin
export GOPATH=$HOME/go
```

### 确保 `~/.bash_profile` 被加载

在某些情况下，您可能需要确保 `~/.bashrc` 被加载到 `~/.bash_profile` 中。可以在 `~/.bash_profile` 中添加以下内容：

```bash
if [ -f ~/.bashrc ]; then
    source ~/.bashrc
fi
```

## 4\. 重新打开终端

配置完成后，关闭并重新打开终端，查看环境变量是否自动生效。您可以运行以下命令检查：

```bash
echo $PATH
```

## 5\. 总结

通过将环境变量配置添加到正确的 Shell 配置文件中，您可以避免每次打开终端后手动执行 `source` 命令。确保使用相应的配置文件（`~/.bash_profile` 或 `~/.zshrc`）并正确设置环境变量。
