在使用supervisor进行进程管理时，启动 `supervisorctl`，启动时候报错

```shell
 unix:///tmp/supervisor.sock no such file
```

然后网上搜了一堆也没解决问题，后来去看`supervisor.log`，发现`supervisord`一启动，过了几秒就自动`to die`了。

后来在`stackOverFlow`看到了这个问题  
尝试去修改了下`/etc/supervisord.conf`中的

```vim
[unix_http_server]
file=/tmp/supervisor.sock   ; (the path to the socket file)
chmod=0700                 ; socket file mode (default 0700)
chown=nobody:nogroup       ; socket file uid:gid owner
username=root              ; (default is no username (open server))
password=root               ; (default is no password (open server))
```

之后再启动就成功了，不会报错，也不会自动die了

```shell
supervisord -c /etc/supervisord.conf
```

注意：用`supervisorctl`查看进程状态时会提示输入账号密码

```
supervisorctl
```

`sock`和`pid`统一放到`/var/run`下面，并且把`run`设个`777`
