# MixPHP 环境要求

```c
Linux, OS X, WSL
PHP >= 7.2
Swoole >= 4.4.4 (websocket >= 4.4.8)
```

我先在本地弄个docker环境

`git clone https://github.com/libenfu/docker-example.git` 或 `下载zip`

按照 `https://www.3pub.cn/index.php/archives/427.html` 教程搭建docker 环境.  
当然自己修改下 `docker-compose.yml` 进入 `cd 2.lnmp-example mixphp` 代码放到 `swoole/code` 目录 运行 `composer`
