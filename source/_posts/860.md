## 什么是 Hermes Agent？

**Hermes Agent** 是由 [Nous Research](https://nousresearch.com/) 开发的开源 AI 智能体框架（MIT 许可证）。它不是简单的聊天机器人或 IDE 插件，而是一个**真正自主的 Agent**——可以在终端、桌面应用、Telegram/微信等 20+ 消息平台运行，具备持久记忆、技能自学习和任务委派能力。

它的核心特性：

-   🧠 **自进化**——会从使用中学习，自动创建和改进技能
-   💬 **20+ 消息平台**——Telegram、Discord、微信、钉钉、飞书等
-   🔧 **60+ 内置工具**——文件操作、网页浏览、代码执行、浏览器自动化
-   💾 **跨会话记忆**——记住你的偏好和历史
-   🤖 **多模型支持**——DeepSeek、Claude、OpenAI、本地模型自由切换
-   📦 **子 Agent 委派**——并行处理复杂任务

* * *

## 安装前提

**唯一的硬性要求是 `git`**，其余依赖（Python 3.11、Node.js、ripgrep、ffmpeg）安装器会自动处理。

## 方式一：桌面版安装（推荐新手）

桌面版包含**图形界面 + 命令行一体**，安装后两者都能用。

### macOS / Windows

1.  访问 [Hermes Agent 官网](https://hermes-agent.nousresearch.com/)，点击 **Download** 按钮下载对应平台的安装包
2.  macOS：打开 `.dmg` 拖入 Applications；Windows：运行 `.exe` 安装器

![Hermes Agent 官网首页 — 下载入口和安装命令](https://www.ikarp.top/index.php/archives/![dowloade.jpg][2] "Hermes Agent 官网首页 — 下载入口和安装命令")

_Hermes Agent 官网首页，提供一键安装脚本、macOS/Windows 下载按钮_

3.  首次启动会自动打开终端设置向导，或运行：

```bash
hermes setup --portal    # 用 Nous Portal 一键配置（推荐）
hermes                   # 开始聊天！
```

### 安装器自动完成的内容

不论哪个平台，桌面安装器都会自动帮你设置好：

-   ✅ uv（快速 Python 包管理器）
-   ✅ Python 3.11（安装到用户目录，不需要 sudo）
-   ✅ Node.js v22（浏览器自动化和 WhatsApp 网桥用）
-   ✅ ripgrep（快速文件搜索）
-   ✅ ffmpeg（音频格式转换，TTS 用）
-   ✅ `hermes` 命令加入 PATH

## 方式二：命令行安装（纯 CLI）

如果你只需要终端中使用，或者要在服务器/VPS 上部署，用安装脚本更轻量。

### Linux / macOS / WSL2 / Android (Termux)

一行命令搞定：

```bash
curl -fsSL https://hermes-agent.nousresearch.com/install.sh | bash
```

安装器会自动检测缺失的依赖并下载，无需手动安装 Python、Node.js 等。

### Windows (PowerShell)

```bash
iex (irm https://hermes-agent.nousresearch.com/install.ps1)
```

### 官方安装文档

![Hermes 官方安装文档 — 可见安装命令和步骤说明](https://www.ikarp.top/index.php/archives/![hermes-install-page.png][3] "Hermes 官方安装文档 — 可见安装命令和步骤说明")

_官方文档安装页面，包含 curl 命令、PowerShell 命令、安装器说明_

完成后重载 shell：

## 配置模型提供方

安装后，最关键的一步是选择 LLM 模型。

### 最快路径：Nous Portal（推荐）

```bash
hermes setup --portal
```

一次订阅覆盖 300+ 个模型 + Tool Gateway（网页搜索、图片生成、TTS、云浏览器），无需分别配置 API Key。

### 手动配置独立 Provider

```bash
hermes model
```

这个交互式命令会带你选择 Provider：

<table><thead><tr><th>Provider</th><th>认证方式</th></tr></thead><tbody><tr><td><strong>Anthropic (Claude)</strong></td><td>API Key 或 OAuth</td></tr><tr><td><strong>OpenAI</strong></td><td><code>OPENAI_API_KEY</code></td></tr><tr><td><strong>DeepSeek</strong></td><td><code>DEEPSEEK_API_KEY</code></td></tr><tr><td><strong>OpenRouter</strong></td><td>OpenRouter API Key（聚合多模型）</td></tr><tr><td><strong>Google Gemini</strong></td><td><code>GOOGLE_API_KEY</code></td></tr><tr><td><strong>xAI (Grok)</strong></td><td><code>XAI_API_KEY</code></td></tr><tr><td><strong>本地模型</strong></td><td>自定义 endpoint + ollama/LM Studio</td></tr></tbody></table>

> 💡 **个人推荐**：日常用 DeepSeek（便宜够用），写代码切 Claude，头脑风暴切 GPT-4o。Hermes 的 `/model` 命令可以随时切换，还可以通过自定义 Skill 实现**自动根据任务类型切换模型**。

## 验证安装

运行以下命令确认一切正常：

```bash

# 2. 运行健康检查
```

## 常见问题

### Q: 安装后 `hermes` 命令找不到？

```bash
# 重新加载 shell
source ~/.bashrc
# 或手动添加 PATH
export PATH="$HOME/.local/bin:$PATH"
```

### Q: 桌面版和命令行版有什么区别？

桌面版 = 图形界面 + 命令行。纯 CLI 安装只有命令行。**无论是哪种方式安装，`hermes` 命令功能完全一致。**

### Q: 能同时配置多个模型吗？

可以！一个配置文件里同时配好多个 Provider，在聊天的任何时候用 `/model` 切换：

```
/model deepseek/deepseek-chat        # 切到 DeepSeek
/model anthropic/claude-sonnet-4     # 切到 Claude
/model openai/gpt-4o                 # 切到 OpenAI
```

### Q: 如何更新？

```bash
hermes update
```

### Q: 能装在 Android 手机上吗？

可以！通过 Termux 安装 CLI 版本：

```bash
pkg update && pkg install git
curl -fsSL https://hermes-agent.nousresearch.com/install.sh | bash
```

或者把 Hermes 运行在服务器上，手机通过 Telegram/微信与其对话。
