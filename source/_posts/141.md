Molokai 是一款流行的 Vim 配色方案，以其深色背景和鲜艳的高亮色彩而著称，适合长时间编程时使用。本文将介绍如何在 Vim 中安装和配置 Molokai 配色方案。

## 1\. 下载 Molokai 配色方案

您可以通过以下方式下载和安装 Molokai 配色方案：

### 1.1 使用 Git 克隆

如果您使用 Git，可以直接克隆 Molokai 配色方案的 GitHub 仓库：

```bash
git clone https://github.com/sickill/vim-monokai.git ~/.vim/colors
```

### 1.2 手动下载

如果您不使用 Git，可以手动下载 Molokai 配色文件。访问 [Molokai GitHub 页面](https://github.com/sickill/vim-monokai)，下载 `molokai.vim` 文件并将其放置到 `~/.vim/colors/` 目录下。

## 2\. 配置 Vim 使用 Molokai

打开或创建 Vim 配置文件 `~/.vimrc`，并添加以下内容：

```vim
" 设置颜色方案
syntax enable
set background=dark
colorscheme molokai
```

## 3\. 启用终端支持

确保您的终端支持 256 色。可以通过在 `~/.vimrc` 中添加以下行来启用：

```vim
if &term =~ 'xterm'
    set t_Co=256
endif
```

## 4\. 重启 Vim

完成上述步骤后，重启 Vim，您应该能看到 Molokai 配色方案生效。

## 5\. 测试配色方案

打开一个文件查看配色效果，确保语法高亮正常。您可以打开一个 Python 文件进行测试：

```bash
vim test.py
```

## 6\. 其他配置

您可以根据个人喜好进一步自定义 Vim 的外观，如设置行号、缩进等。例如：

```vim
set number          " 显示行号
set relativenumber  " 显示相对行号
set tabstop=4       " 设置 Tab 为 4 个空格
set shiftwidth=4    " 设置自动缩进为 4 个空格
set expandtab       " 使用空格代替 Tab
```
