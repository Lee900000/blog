# mysql查询如何区分大小写

在`mysql`中，可以利用select查询语句配合`binary`关键字来区分大小写，`select`语句用于查询数据，`binary`关键字用于区分大小写，语法为

```c
select * from 表名 WHERE binary 字段=字段值
```

mysql查询如何区分大小写  
mysql中查询默认是区分大小写的，但是在mysql中默认不区分大小写。

## 解决办法：

`mysql`可以在SQL语句中加入 `binary`来区分大小写。`BINARY`不是函数，是类型转换运算符，它用来强制它后面的字符串为一个二进制字符串，可以理解为在字符串比较的时候区分大小写。

# 一、查询语句上加binary

```c
   select * from users WHERE binary user_name = '小王' AND status != 0
```

# 二、建表时加binary

```c
code varchar(10)  binary
```

执行完上面的sql后，对该表的查询就能区分大小写了。
