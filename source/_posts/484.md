# 1、获取今天的日期

```c
log=$(date -d "now" +%Y-%m-%d)
echo ${log}
```

# 2、获取昨天的日期

```c
log2=$(date -d "yesterday" +%Y-%m-%d)
echo ${log2}
```

或者

```c
log2=$(date -d "1 day ago" +%Y-%m-%d)
echo ${log2}
```

# 3、获取前天的日期

```c
log3=$(date -d"2 day ago" +%Y-%m-%d)
echo ${log3}
```

# 4、获取具体日期的前几天

```c
log4=$(date -d"15 day ago 2017-04-16" +%Y-%m-%d)

echo ${log4}
```

输出：2017-04-01
