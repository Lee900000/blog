判断一个字符串是否包含乱码：

1.  可以用正则匹配，但是你需要知道乱码大概包括的符号有哪些。
2.  运用黑魔法之`json_encode($string) === 'null'` 来判断。如果字符串中含有乱码，`json_encode`该字符串就会返回`null`。

```php
function isGarbled($content)
{
    $json = \json_encode((array)$content);

    return $json == false;
}
```
