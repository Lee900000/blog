# 使用 yum 升级 Swoole 版本

在使用 Swoole 进行开发时，及时更新到最新的版本是保持系统稳定性和安全性的重要措施之一。本文将介绍如何使用 yum 工具来升级 Swoole 的版本，并提供一些相关的注意事项。

## 1\. 查看当前安装的 Swoole 版本

首先，我们需要查看当前系统中已安装的 Swoole 版本。可以通过以下命令来查询：

```bash
php -m | grep swoole
```

或者

```bash
php -i | grep swoole
```

## 2\. 添加 Swoole Yum 仓库

Swoole 提供了官方的 Yum 仓库，我们需要将其添加到系统中，以便从该仓库获取最新的 Swoole 版本。可以按照以下步骤操作：

### 通过编辑 `/etc/yum.repos.d/swoole.repo` 文件添加 Swoole 仓库：

```bash
sudo nano /etc/yum.repos.d/swoole.repo
```

### 将以下内容添加到文件中并保存：

```ini
[swoole]
name=swoole
baseurl=https://rpms.swoole.com/centos/$releasever/$basearch
gpgcheck=0
enabled=1
```

## 3\. 更新 yum 缓存

添加完 Swoole 仓库后，需要更新 yum 缓存，以便系统能够识别并获取最新的软件包信息：

```bash
sudo yum makecache
```

## 4\. 升级 Swoole

现在，我们可以使用 yum 命令来升级 Swoole 到最新版本：

```bash
sudo yum update swoole
```

## 5\. 验证升级结果

升级完成后，我们需要再次验证 Swoole 的版本是否已经更新到最新版本：

```bash
php -m | grep swoole
```

或者

```bash
php -i | grep swoole
```
