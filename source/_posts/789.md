在 CentOS 上使用 `yum` 安装 Node.js 非常简单。可以按照以下步骤进行：

### 1\. 添加 NodeSource 仓库

NodeSource 提供了 Node.js 的官方仓库。首先，添加你需要的 Node.js 版本仓库，例如 Node.js 16.x：

```bash
curl -sL https://rpm.nodesource.com/setup_16.x | sudo bash -
```

![2025-05-14T01:12:03.png](/assets/migrated/2e734c59ee95dcb48dd7.png "2025-05-14T01:12:03.png")

### 2\. 安装 Node.js

接下来，使用 `yum` 安装 Node.js：

```bash
sudo yum install -y nodejs
```

![2025-05-14T01:13:09.png](/assets/migrated/4e09496e9e06773f5ea7.png "2025-05-14T01:13:09.png")

### 3\. 验证安装

安装完成后，检查 Node.js 和 npm 版本以确认安装成功：

```bash
# node -v
v16.20.2

# npm -v
8.19.4
```

### 4\. 更新 npm（可选）

如果需要更新 npm 到最新版本，可以使用以下命令：

```bash
sudo npm install -g npm@latest
```
