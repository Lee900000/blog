要清除在 `CentOS` 上的本次访问记录，你可以执行以下步骤：

1.  清除 `Bash` 命令历史记录：`Bash` 终端会记录你在命令行中输入的历史命令。要清除本次会话中输入的命令历史记录，可以运行以下命令：
    
    ```shell
    history -c && history -w
    ```
    
2.  清除当前用户的登录记录：Linux 系统会记录用户的登录信息，包括登录时间和来源 IP 等。要清除当前用户的登录记录，可以使用以下命令：
    
    ```shell
    > ~/.bash_history
    ```
    
3.  清除 SSH 登录记录（如果适用）：如果你使用 SSH 远程登录到 CentOS，系统会记录 SSH 登录信息。要清除 SSH 登录记录，可以编辑 `/var/log/secure` 文件并删除相关的条目。请注意，这需要 root 权限。
4.  清除系统日志：要清除系统日志，可以使用以下命令：
    
    ```shell
    sudo truncate -s 0 /var/log/messages
    sudo truncate -s 0 /var/log/secure
    ```
    

上述命令会将 `/var/log/messages` 和 `/var/log/secure` 文件的内容清空。同样，这需要 `root` 权限。

请注意，以上步骤只会清除本次会话期间的记录。如果你希望清除更多的历史记录，可能需要执行其他操作或修改系统配置。此外，如果你想保护隐私或确保安全性，请考虑采取其他措施，如使用私密浏览模式、使用匿名代理等。
