在 MySQL 中，字符串截取可以通过多种函数来实现。以下是一些常见的字符串截取方法及其用法。

## 1\. 使用 `SUBSTRING()` 函数

`SUBSTRING()` 函数用于从指定位置开始截取字符串。

### 1.1 语法

```sql
SUBSTRING(str, start, length)
```

-   `str`: 要截取的字符串。
-   `start`: 开始位置（从 1 开始）。
-   `length`: 要截取的长度（可选）。

### 1.2 示例

```sql
SELECT SUBSTRING('Hello, World!', 1, 5);  -- 输出 'Hello'
SELECT SUBSTRING('Hello, World!', 8);     -- 输出 'World!'
```

## 2\. 使用 `LEFT()` 函数

`LEFT()` 函数用于从字符串的左侧开始截取指定长度的字符串。

### 2.1 语法

```sql
LEFT(str, length)
```

### 2.2 示例

```sql
SELECT LEFT('Hello, World!', 5);  -- 输出 'Hello'
```

## 3\. 使用 `RIGHT()` 函数

`RIGHT()` 函数用于从字符串的右侧开始截取指定长度的字符串。

### 3.1 语法

```sql
RIGHT(str, length)
```

### 3.2 示例

```sql
SELECT RIGHT('Hello, World!', 6);  -- 输出 'World!'
```

## 4\. 使用 `SUBSTRING_INDEX()` 函数

`SUBSTRING_INDEX()` 函数用于根据指定的分隔符截取字符串。

### 4.1 语法

```sql
SUBSTRING_INDEX(str, delimiter, count)
```

-   `count`: 如果为正，返回从字符串开始到指定分隔符的部分；如果为负，返回从字符串末尾到指定分隔符的部分。

### 4.2 示例

```sql
SELECT SUBSTRING_INDEX('apple,banana,cherry', ',', 2);  -- 输出 'apple,banana'
SELECT SUBSTRING_INDEX('apple,banana,cherry', ',', -1); -- 输出 'cherry'
```

## 5\. 使用 `INSTR()` 和 `SUBSTRING()`

结合使用 `INSTR()` 和 `SUBSTRING()` 可以实现更复杂的字符串截取。

### 5.1 示例

从某个特定字符开始截取：

```sql
SELECT SUBSTRING('Hello, World!', INSTR('Hello, World!', ',') + 1);  -- 输出 ' World!'
```
