# 解决 Crontab 失效的问题

当定时任务的 `Crontab` 失效时，其中一个可能的原因是因为 `cron` 服务未启动。通过以下步骤，你可以启动 `cron` 服务并解决该问题。

首先，检查 `cron` 服务的运行状态：

```bash
$ ps aux | grep cron
```

如果没有看到与 cron 相关的进程，则表示 cron 服务未启动。

接下来，启动 cron 服务：

```bash
$ systemctl start crond
```

再次检查 cron 服务的运行状态：

```bash
$ ps aux | grep cron
```

确保 `cron` 服务已成功启动后，将其设置为开机自启动：

```bash
$ systemctl enable crond
```

你还可以查看 `cron` 服务的日志文件，以便进一步排查问题：

```bash
$ tail -f /var/log/cron
```

确认 `Crontab` 编辑已完成：

```bash
Jun 19 19:28:08 cronjob-01 crontab[757]: (root) END EDIT (root)
```

通过以上步骤，你可以启动 `cron` 服务，并确保 `Crontab` 任务正常执行。
