```
2025/01/19 23:51:09 [crit] 9471#9471: *76105 open() "/var/lib/nginx/tmp/fastcgi/0/69/0000000690" failed (13: Permission denied) while reading upstream, client: 127.0.0.1, server: localhost, request: "GET /index.php/index?addtabs=1&sort=show_name&order=desc&filter=%7B%7D&op=%7B%7D&_=1 HTTP/1.1", upstream: "fastcgi://127.0.0.1:9000", host: "127.0.0.1:8009"
```

## 【解决方法】

```
vi /usr/local/nginx/conf/nginx.conf

#user nobody;
```

修改为

```
user root;
```

重启nginx

这么改只是 临时解决方案 不安全 罪啊后的方式还是针对目录授权
