`PHP` 升级到 `7.4` 之后，会收到 `Array and string offset access syntax with curly braces is deprecated` 的错误，这是因为：

`PHP7.4` 不再支持使用大括号访问数组以及字符串的偏移，就是不支持数组`{}`写法，统一为数组`[]`。

比如：

```
$index{$start+7}
```

就要改成：

```
$index[$start+7]
```
