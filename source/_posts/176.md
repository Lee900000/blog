在 Linux 系统中，进程管理是一个重要的任务。pstree 是一个常用的命令行工具，用于以树状结构显示系统中运行的进程。本文将介绍如何在 Linux 上安装和使用 pstree，以及它的一些常见用法。

### 1\. 安装 pstree

pstree 在大多数 Linux 发行版的官方仓库中都有提供，因此安装非常简单。下面是一些常见的包管理器命令，用于在不同的发行版上安装 pstree：

-   在 Debian/Ubuntu 上，使用 apt-get 安装：

```shell
sudo apt-get install psmisc
```

-   在 CentOS/RHEL 上，使用 yum 安装：

```shell
sudo yum install psmisc
```

-   在 Fedora 上，使用 dnf 安装：

```shell
sudo dnf install psmisc
```

请根据你所使用的 Linux 发行版选择相应的命令进行安装。

### 2\. 使用 pstree

安装完成后，你就可以在命令行中使用 pstree 命令了。下面是一些常见的用法示例：

-   显示当前用户的进程树：

```shell
pstree
```

-   显示指定用户的进程树：

```shell
pstree -u username
```

将 `username` 替换为你要查看的用户名。

-   显示完整的进程树，包括命令行参数：

```shell
pstree -a
```

-   显示进程树的 ASCII 图形表示：

```shell
pstree -A
```

-   以紧凑模式显示进程树：

```shell
pstree -c
```

以上只是 pstree 的一些常见用法示例，你可以通过查看 `man` 页面或者使用 `pstree --help` 命令来获取更多的选项和用法信息。
