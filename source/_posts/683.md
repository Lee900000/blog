当在 Linux 中想要查看进程的运行时间时，可以使用 `ps` 命令结合 `etimes` 选项来获取进程的运行时间。以下是一个使用 Markdown 格式写技术博客的示例：

# 如何在 Linux 中获取进程运行时间

在 Linux 系统中，我们经常需要了解进程的运行时间，以便进行系统性能分析和故障排除。本文将介绍如何使用 `ps` 命令来获取进程的运行时间。

## 步骤

1.  打开终端，进入 Linux 终端界面。
2.  使用以下命令来获取进程运行时间：
    
    ```bash
    ps -eo pid,comm,etimes --no-headers
    ```
    
    -   `ps` 命令用于显示当前运行进程的信息。
    -   `-eo` 选项指定要显示的字段，`pid` 表示进程ID，`comm` 表示进程名称，`etimes` 表示进程的运行时间（以秒为单位）。
    -   `--no-headers` 选项用于去除输出结果中的表头。
3.  运行上述命令后，将会显示进程的运行时间列表，类似于以下输出：
    
    ```bash
    1234  example_process  3600
    5678  another_process  1800
    ```
    
    上述输出中，第一列是进程ID，第二列是进程名称，第三列是进程的运行时间（以秒为单位）。
    
4.  根据输出结果，你可以查看每个进程的运行时间，并进行进一步的分析和处理。

## 结论

通过使用 `ps` 命令的 `etimes` 选项，我们可以轻松获取进程的运行时间。这对于系统管理、性能监控和故障处理非常有用。
