如果`docker-compose.yml`如下，则用`docker-compose up -d`启动起来的容器可能会立即停止。

```
version: '2'
services:
  mir-http-repo:
    image: 172.16.101.192/mir_docker/centos6.7_repo_jinzhong:v1.0
    container_name: mir-http-repo
    ports:
      - 8088:8088
```

解决办法：加上`tty`为`true`

```
version: '2'
services:
  mir-http-repo:
    image: 172.16.101.192/mir_docker/centos6.7_repo_jinzhong:v1.0
    container_name: mir-http-repo
    ports:
      - 8088:8088
    tty: true
```
