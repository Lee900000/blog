# 1\. 切换到用户主目录

```c
$ cd　　
```

# 2\. 编辑或新建`.bash_profile`文件

# 3\. 添加别名

命令别名设置语法：

```c
alias [别名]='[指令名称]'
```

注意：等号两边均无空格，指令名称中如有空格，需用引号包裹

例如：

```c
alias ll='ls -Alh'
```

# 4\. 重载该配置文件

```c
$ source .bash_profile
```

# 5\. 查看当前所有别名设置

```c
$ alias
```

注：`Mac`别名设置与`Linux`大体相同，仅配置文件不同。可参考`Linux alias`命令
